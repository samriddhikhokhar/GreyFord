# Greyford Engineering 🏗️

A modern construction and engineering company website built using **HTML5, CSS3, and JavaScript** in a single HTML file.

## 🌐 Live Demo

🔗 **[View Live Website](https://samriddhikhokhar.github.io/GreyFord/)**

## 📌 About the Project

Greyford Engineering is a frontend web development project designed to showcase a professional construction business. It features a clean layout, a bold black-and-gold color palette, service sections, company information, and a contact form.

## ✨ Features

* Modern and professional user interface.
* Black-and-gold visual theme.
* Construction and engineering service sections.
* Company introduction and quality highlights.
* Step-by-step work process section.
* Contact form for project inquiries.
* Interactive elements powered by JavaScript.
* HTML, CSS, and JavaScript combined in a single file.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layout, and visual design.
* **JavaScript** — Interactive functionality.

1. Clone or download this repository.

4. Explore the website.
